# QuickNotes System Design

## Description

QuickNotes is a note-taking application that demonstrates API integration using JSONPlaceholder and includes backend design documentation for scaling to 1 million users.

## Running the API Client

1. Open project folder.
2. Open index.html in a browser.
3. Click Load Notes.
4. Create and delete notes.
